
# React Users App
A clean, fully-typed React application for managing a list of users, built with TypeScript and Vanilla CSS.

 # How to Run
🚀  [Посмотреть проект вживую (Live Demo)](https://5555nika.github.io/UserList/) 

## 🚀 Features
- **Add Users:** Add new users with dynamic form input.
- **Edit Users:** In-place user editing with pre-filled forms.
- **Delete Users:** Remove users from the list instantly.
- **Responsive UI:** Clean flexbox layout with custom CSS variables and hover states.
- **Unit Tested:** Complete test coverage using Vitest and React Testing Library.
  
## 🛠️ Tech Stack
- **Framework:** React 19, TypeScript
- **Build Tool:** Vite
- **Styling:** Vanilla CSS (CSS Variables, Flexbox)
- **Icons:** React Icons (`react-icons/io5`)
- **Testing:** Vitest, React Testing Library, JSDOM
