

# React Users Management App
A lightweight, fully-typed React application for managing users (CRUD operations) built with modern frontend best practices.

 # How to Run
🚀  [Посмотреть проект вживую (Live Demo)](https://5555nika.github.io/UserList/) 

## 🚀 Features
- **User Management:** Create, view, edit, and delete user records.
- **Form Controls:** Controlled inputs with type conversion and state resetting.
- **Modal Views & Tables:** Clean UI powered by Ant Design components.
- **Automated Testing:** Comprehensive unit and integration test coverage using Vitest and React Testing Library.
  
## 🛠️ Tech Stack
- **Core:** React 19, TypeScript
- **Build Tool:** Vite
- **UI & Icons:** Ant Design, React Icons
- **Testing:** Vitest, React Testing Library, JSDOM
